# SshManager — Linux 远程管理工具（C# / Avalonia）

用 C# 编写的图形化 SSH 服务器管理工具：执行任意命令（**含真·交互终端**）、管理文件（上传/下载/删除/重命名/**在线编辑**、**无权限目录 sudo 提权访问**）、查看与卸载已安装应用（apt / snap / flatpak）、**Docker 容器与镜像管理**、**网络参数配置（IP / 网关 / DNS / WiFi / 防火墙 / 主机名）**、实时查看系统状态。服务器端**无需安装任何额外软件**，只要有 SSH 服务（默认 22 端口）即可。

> 技术栈：.NET 8 · Avalonia UI 11 · SSH.NET · CommunityToolkit.Mvvm（MVVM）
> 适配系统：Windows / Linux / macOS 均可编译运行（跨平台）

## v0.8.0 更新日志

- **文件管理等全部工具栏自适应窗口宽度**：窗口缩小时按钮不再被裁剪——
  - 文件管理操作行（新建文件夹 / 新建文件 / 上传 / 上传文件夹 / 下载 / 编辑 / 重命名 / 属性 / 删除 / 显示隐藏）改为**自动换行布局**，窄窗口时按钮折到下一行，全部可达；导航行路径框可压缩并设最小宽度；
  - 同类布局问题全局排查并修复：应用中心（筛选 / 安装行）、Docker（状态横幅 / 工具栏 / 日志面板头）、网络设置（防火墙卡片头）、部署执行栏、命令台（模式切换 / PTY 工具条）。
- **修复：访问无权限目录崩溃（PermissionDeniedException）**：
  - 根因是“未开启自动 sudo 提权”时底层权限异常直接穿透 UI。现 Core 层将其转为友好提示（指引用户在连接设置开启提权），不再出现未处理异常；
  - 目录选择对话框（部署路径等）改用与文件管理一致的 **SFTP 优先 + sudo 降级** 逻辑，无权限目录同样可浏览（弹密码后重试）；
  - 新增**全局异常兜底**（UI 线程 / 后台任务 / 域三个通道）：任何漏网异常记录到 `%APPDATA%\SshManager\error.log` 并保持界面存活，进程不再闪退。
- **编辑器滚动条修复**：编辑区文本超出可视范围后，**内部自动出现垂直滚动条**（关闭自动换行时超宽行还有水平滚动条）；编辑区继续占满卡片剩余空间，长文档可完整滚动查看。
- **交互终端（PTY）三项改进**：
  - **宽度撑满容器**：修复 PTY 模式区域被布局停靠为“左停靠”导致的右侧大片空白，终端现在横向撑满内容区；
  - **文字与光标严格网格对齐**：重写渲染层——每个字符独立锚定在自己的单元格内（字符级字形缓存，稳态渲染零构建成本），文字、背景色块、光标三者完全同网格，不再随行长累积偏移；
  - **光标改为 Windows 控制台风格的细竖线**（约 530ms 闪烁，输入/输出后立即可见；失焦时常亮），紧贴最后一个字符，不再是空心方块；
  - **终端配色跟随应用主题**：与左上角深 / 浅主题按钮联动——深色主题维持原配色；浅色主题自动切换为浅底深字（含基础 16 色的浅色亮度适配版），切换即时生效。
- **顶部菜单“命令台”更名为“终端”**，所有顶部标签及侧栏按钮的图标与文字统一**垂直居中**。
- **系统概览“系统”卡片键值对齐**：左右两列统一字号（12.5px）与固定行高（26px）并垂直居中，“主机名 / zg”等不再上下错位；属性对话框（InfoDialog）同类键值行一并对齐。

## v0.7.0 更新日志

- **文件管理支持 sudo 提权访问无权限目录/文件**（如 `/root`、`/etc/shadow`）：
  - 浏览/进入无权限目录：SFTP 优先，遇到“权限不足”自动降级为 `sudo find` 列目录（名称/大小/权限/时间完整解析），界面显示 **“sudo 提权访问”** 徽章；
  - 双击编辑无权限文件：自动降级 `sudo cat` 读取，编辑标签显示 **“sudo 读取”** 徽章；保存沿用既有的 sudo 兜底（保留原属主与权限）；
  - 下载无权限文件/目录：自动降级 `sudo cat` 流式下载（进度正常显示）；递归下载 `/root` 级目录同样支持；
  - 上传到无权限目录：自动降级为“`/tmp` 中转 + `sudo cp`”模式；远程目录不存在时 `sudo mkdir -p` 兜底；
  - 需要 sudo 密码时弹窗输入一次后自动重试；连接对话框新增 **“无权限目录自动 sudo 提权访问”** 开关（默认开启，按服务器保存）；
  - 正常路径仍走 SFTP 直连（速度快），仅权限不足时才降级，全程无感知。
- **命令台新增“交互终端（PTY）”模式**（顶部模式切换，默认仍为单次执行）：
  - 真实 PTY 会话（xterm-256color）：`cd` / `export` / `alias` 等 shell 状态**持久生效**，`sudo -i`、`su`、`top`、`htop`、`less`、`tail -f`、`vim` 等**所有交互式命令可用**（sudo 密码在终端里直接输入）；
  - 内置自研轻量 xterm 终端模拟器：ANSI 16/256/RGB 真彩色、粗体/暗淡/反色、光标移动与显隐、清屏、插删行/字符、滚动区、备选屏幕（全屏程序）、标题栏（OSC）；滚轮/Shift+PgUp/PgDn 回看 5000 行历史；
  - 键盘完整映射：Ctrl+字母、方向键/Home/End/Delete/功能键、Ctrl+←/→（按词跳转）、Ctrl+V / Shift+Insert 粘贴；终端区域尺寸变化自动通知服务器（vim/top 不再错位）；
  - 工具条：**清屏**、**Ctrl+C**、**重新打开**（重置 shell）；概览页/Docker 页的快捷命令跳转命令台时自动切回单次模式执行；
  - 单次模式保留不变：流式输出、退出码、↑↓ 历史、命令库 88 条；`sudo -i` 等在单次模式下会提示切换到交互终端。
- **防火墙（UFW）规则列表修复 + 规则修改**：
  - 修复：中文系统（zh_CN locale）下 ufw 输出本地化文本导致**规则列表永远为空**的问题——所有 ufw 读取强制 `LC_ALL=C` 英文输出，任何服务器上解析稳定；
  - 修复：默认策略解析正则与 ufw 实际输出格式不符导致“当前：入站/出站”显示为空；
  - 规则列表每行新增 **“修改”** 按钮：弹窗回填原规则（动作/方向/端口/协议/来源），确认后“删除原编号 + 添加新规则”一次执行，带命令预览与 IPv6 行提示；支持**出站（out）规则**的解析与重建。
- 其他：会话断开时自动关闭 PTY 终端；编辑器对 sudo 读取的文件跳过“外部修改检测”（无权 stat 不再误报）。

## 构建与运行

需要 .NET 8 SDK（`dotnet --version` ≥ 8.0）。

```bash
# 还原 + 编译（Debug）
dotnet build

# 直接运行
dotnet run --project src/SshManager.App

# 发布小体积单文件 exe（不带运行时，目标机器需装 .NET 8）
dotnet publish src/SshManager.App -c Release -r win-x64 \
    --self-contained false -p:PublishSingleFile=true \
    -o publish/

# 发布自包含 exe（目标机器无需任何环境，约 90MB）
dotnet publish src/SshManager.App -c Release -r win-x64 \
    --self-contained true -p:PublishSingleFile=true \
    -o publish-selfcontained/
```

配置保存位置：`%APPDATA%/SshManager/`（Windows）或 `~/.config/SshManager/`（`profiles.json` 服务器列表、`ui.json` 界面偏好）。**密码永不落盘**，sudo 密码仅保存在内存。

## 设计说明

- **服务器零依赖**：所有功能通过标准 SSH 通道完成（命令 + SFTP），服务器不需要装 agent。
- **sudo 双方案**：命令包装 `echo '密码' | sudo -S -p '' …`，密码经 stdin 传递，不出现在命令行参数与日志中；密码登录时复用登录密码，私钥登录时按需弹窗。
- **危险操作二次确认**：删除、卸载、Docker 删除/清理、防火墙启停、网络参数下发等均有确认弹窗；危险命令在命令库中执行前确认。
- **传输通道分离**：交互操作（列目录/删除等）与大文件传输使用独立 SFTP 连接，互不阻塞。
